\# Deepfake Detection



\## 📌 Overview

This project detects deepfake content using machine learning and provides a web interface built with Flask.



\## 🗂️ Project Structure

\- `app.py` → Flask web app

\- `train.py` → Model training

\- `evaluate.py` → Model evaluation

\- `templates/` → HTML templates

\- `static/` → CSS/JS assets
